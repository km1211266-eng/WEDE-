# Kwacha Coffee Roasters — Website Project

WEDE5020 Portfolio of Evidence. A small-business website for Kwacha Coffee
Roasters, an independent Johannesburg specialty coffee roastery.

## Pages

- `index.html` — Home
- `about.html` — About Us
- `products.html` — Our Roasts
- `contact.html` — Contact / Enquiry
- `faq.html` — FAQ

## Tech Stack

- HTML5
- CSS3 (mobile-first, responsive)
- Vanilla JavaScript (planned for Part 3)

## Changelog

### Part 1
- Initial HTML file structure created (5 pages).
- Consistent header, navigation, and footer across all pages.

### Part 2
- Linked Google Fonts (Poppins for headings, Open Sans for body text).
- Added CSS reset and base styles (colour scheme, box-sizing, base typography).
- Styled header/navigation using Flexbox (sticky header, hover/focus/active states on nav links).
- Built hero section layout with Flexbox and added a responsive hero image using `<picture>` and `srcset`/`sizes`.
- Styled card grids (home, products) using CSS Grid with `auto-fit`/`minmax` for automatic reflow.
- Added visual styling to buttons and cards (`background-color`, `border-radius`, `box-shadow`) with `:hover`, `:focus`, and `:active` states.
- Styled enquiry form using Flexbox with focus states on inputs.
- Added responsive breakpoints at 768px (tablet) and 480px (mobile): header stacks vertically, nav becomes a column, card grid collapses to one column, hero stacks and centres.
